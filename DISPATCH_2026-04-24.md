## Coordination Protocol — READ BEFORE DISPATCHING ANY CHAT

### Branching
Every chat creates its own branch off current `main`:
```
git fetch origin
git checkout -b ws/<short-name> origin/main
```
No chat pushes to `main`. Every chat pushes its branch and leaves a one-paragraph summary at the top of the branch description. This window merges after review + regression.

### Golden files — touched by this window ONLY
- `CLAUDE.md` — every workstream writes a scratch `SESSION_LOG_ws-<name>.md` in repo root. This window consolidates into CLAUDE.md at end of day. **No chat edits CLAUDE.md directly.**

### Git hygiene (burned into CLAUDE.md — enforce)
- **Never** `git add -A` or `git add .` — explicit file paths only.
- Pull before touching shared files.
- CRLF drift on Windows: if `git diff --stat` shows thousands of delta lines on a barely-touched file, it's line endings — flag and skip, don't normalize mid-session.
- After any `Write`/`Edit` on a Python source or CLAUDE.md, `wc -l <path>` + `tail -3 <path>` to confirm no truncation.
- Regression tests must exercise the production path (DB round-trip, HTTP request, CLI subcommand) — tautological in-test scaling is forbidden.

### Reference baselines — must be preserved across every merge
- GSX-R 1000 K5 → **10.033s** (±0.02s)
- YZF-R1 4C8 → **10.286s** (±0.02s)

Any change that moves these by more than ±0.02s is a regression until proven otherwise.
