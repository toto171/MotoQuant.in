# MotoQuant Pro -- developer / CI-only dependencies
# Install with: pip install -r requirements-dev.txt
#
# These are only needed to run the test suite + tooling, not to run
# the API server in production. Production runtime deps live in
# requirements-api.txt.

# Test runner (already required by every existing tests/test_*.py
# but pinned here so a fresh dev checkout `pip install -r
# requirements-dev.txt` is enough to run `pytest` straight away).
pytest>=7.0,<10

# Property-based testing — powers tests/test_physics_invariants.py
# (monotonicity invariants for mass / power / Cd / frontal_area).
# The test file is gated on `pytest.importorskip("hypothesis")` so
# the rest of the suite still runs without this dependency.
hypothesis>=6.100,<7

# ── Parity with CI (added 2026-07-25 audit) ─────────────────────────────────
# AGENTS.md §1 and the Makefile both promise "the make targets mirror CI
# exactly, so green locally ≈ green in CI". They did not: `make install`
# installs only requirements-api.txt + requirements-dev.txt, and none of the
# packages below were in either — while .github/workflows/ci.yml installs all
# of them. Consequences on a fresh checkout: `make check` died immediately with
# "ruff: command not found" (it is the very first command of the documented
# loop), and `make test` silently SKIPPED the sobol/surrogate tests that CI
# actually executes. Keep this list in sync with the CI install step.

# Lint + format. `make lint`, `make fmt-check`, `make check` and the
# pre-commit hook all shell out to it; CI runs it as its first two steps.
# Floor 0.16.2: ruff 0.16 began formatting Python code blocks inside .md
# files, so an unpinned CI resolving a newer ruff than the dev box flags
# files the local `make check` calls clean (bit us 2026-08-08, the day CI
# came back to life). Keep the window one minor wide so local == CI.
ruff>=0.16.2,<0.17

# Coverage instrumentation for the main-push CI tier (`--cov=motoquant`).
pytest-cov>=5,<8

# Optional analysis deps. Without them tests/test_analysis.py (sobol) and
# tests/test_surrogate.py skip large blocks that CI runs for real.
SALib>=1.4,<2
scikit-learn>=1.3,<2

# CLI-only physics tooling (moved OUT of requirements-api.txt 2026-08-11 —
# no API route reaches it): the auto-calibrator's DE + Nelder-Mead fit
# (calibration/calibrator.py) and the Sobol sampler (analysis/surrogate_data.py)
# both guard their scipy imports and degrade gracefully when it is absent,
# which is exactly what production now does.
scipy>=1.10.0,<2

# Builds the optional Rust physics core's PyO3 extension (`make native`;
# rust/motoquant-core, docs/RUST_CORE.md). Not needed to run anything — the
# pure-Python engine is the reference and remains the default.
maturin>=1.5,<2
