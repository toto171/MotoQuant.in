# MotoQuant -- API server dependencies (production)
# Install with: pip install -r requirements-api.txt
#
# Every dependency carries an upper bound (next major) so a surprise major
# release can never walk into a production image. The Docker image installs
# the fully-pinned transitive closure from requirements-api.lock instead —
# regenerate it with `make lock` whenever this file changes.

# Web framework
fastapi>=0.162.2,<1.0
uvicorn[standard]>=0.54.0,<1.0
pydantic>=2.14.3,<3

# Physics engine core (numpy ONLY — physics.py + submodels are numpy+stdlib).
# scipy was removed 2026-08-11: the API's only reachable scipy sites are the
# CLI-only auto-calibrator (calibrator.py, guarded try-import with graceful
# fallback) and the CLI-only Sobol sampler (surrogate_data.py, lazy import
# with a numpy fallback) — no API route executes either, verified by tracing
# every calibration/analysis import from api.py. ~113 MB off the Docker image
# and one CVE surface less. scipy lives in requirements-dev.txt for CLI work.
numpy>=2.2.6,<3

# File uploads
# Floor 0.0.18: CVE-2024-53981 (multipart boundary DoS) fixed in 0.0.18;
# the parser is reachable from the two unauthenticated calibration uploads.
python-multipart>=0.0.32,<1.0

# Database
# (sqlite3 is stdlib -- no extra package needed)

# NL chat layer (POST /api/chat, `motoquant chat`): Claude only.
# The server's own key comes from the ANTHROPIC_API_KEY environment variable
# (Render dashboard, never a file). Visitors may send their own key per
# request in the X-Anthropic-Key header; it is used for that request only.
# Without either key, chat answers "assistant_unavailable".
# 2.x speaks API version 2026-10-21 and is built on httpx2.
anthropic>=2.8.0,<3

# Chat-agent web lookup (motoquant/llm/webtools.py). requests is a DIRECT
# dependency (it used to arrive transitively via the now-removed razorpay SDK)
# so no dependency change can ever silently remove the agent's
# web_search/web_fetch tools.
# Optional env: SEARCH_PROVIDER=brave|serper + SEARCH_API_KEY for a paid
# search API; without a key the DuckDuckGo HTML fallback is used.
# MOTOQUANT_WEB_TOOLS=0 disables web tools entirely.
# Floor 2.32.4: CVE-2024-35195 (cert-verify bypass, fixed 2.32.0) +
# CVE-2024-47081 (.netrc credential leak, fixed 2.32.4).
requests>=2.34.2,<3

# Optional production observability — error tracking + performance traces.
# Soft-dep: motoquant.observability.init_sentry() no-ops if SENTRY_DSN env
# var is not set. Enable on Render by setting SENTRY_DSN to your project's
# DSN URL (https://...sentry.io/...).
# Floor 2.11.0: CVE-2024-40647 (env-var exposure, fixed 2.8.0) + the
# `disabled_integrations` init kwarg used by motoquant/observability.py
# (added in 2.11.0).
sentry-sdk[fastapi]>=2.74.0,<3
