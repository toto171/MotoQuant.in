Task list:

1. DB schema (motoquant/database/schema.py):
   - `users`: id, email (unique), created_at, tier (free|pro|studio), stripe_customer_id (unused; keep for future), razorpay_customer_id, is_active
   - `sessions`: id, user_id, jwt_id, expires_at, created_at, revoked

   - `subscriptions`: id, user_id, razorpay_subscription_id, tier, status (active|past_due|cancelled), current_period_end, created_at
   - `license_keys`: id, user_id, key_hash, device_id, activated_at, last_seen_at, revoked
   Write migration logic in schema.py that checks for table existence and creates on the fly — same pattern as existing tables.

2. motoquant/auth.py:
   - `POST /api/auth/magic-link` — accept email, create magic_link row with 10-minute TTL, send email via a pluggable backend (for dev: print to stdout; for prod: SMTP via env vars or Resend.com API). Idempotent on repeat requests within 60s (rate limit).
   - `POST /api/auth/verify` — accept token from magic link, create session, return JWT (15-min access + 30-day refresh).
   - `POST /api/auth/refresh` — new access token from valid refresh.
   - `POST /api/auth/logout` — revoke session.
   - `GET /api/auth/me` — returns {email, tier, subscription_status, license_keys: [...]}.
   - `require_tier(tier_name)` FastAPI dependency — reads JWT from Authorization header, looks up user, verifies tier >= required. Returns 402 Payment Required (not 401) if authenticated but wrong tier — this lets the client show an upgrade CTA.

3. motoquant/subscriptions.py:
   - `POST /api/subscriptions/checkout` — creates a Razorpay subscription (plan_id from env), returns the hosted payment URL. Use the razorpay Python SDK (add to requirements-api.txt).
   - `POST /api/subscriptions/webhook` — verifies Razorpay signature, updates subscriptions table, upgrades user tier on `subscription.activated`, downgrades on `subscription.cancelled`. Idempotent on duplicate webhook deliveries.
   - `POST /api/subscriptions/license-key` — generates a new license key for the user's desktop app (UUID v4, stored hashed). Returns plaintext ONCE. Max keys per tier: pro=1, studio=5.
   - `POST /api/subscriptions/license-key/validate` — desktop app calls this on startup. Verifies key_hash matches, updates last_seen_at. Returns tier.
   - `POST /api/subscriptions/cancel` — cancels at period end via Razorpay.
